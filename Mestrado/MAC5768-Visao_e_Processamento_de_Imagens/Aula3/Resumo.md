### Indexing
Indexing refers to how the location of a pixel is specified within an image. The text describes two main conventions:
* **Coordinate Indexing:** This method identifies a pixel's location using standard 2-D coordinates. 
* **Linear Indexing:** Extensively used in programming, this method represents pixel locations as a 1-D string of nonnegative integers calculated as offsets from the origin (0,0). Linear indices are typically generated by scanning the image either row-by-row or column-by-column. For instance, in a column scan of an image with $M$ rows, the linear index $\alpha$ for a pixel at coordinates $(x, y)$ is given by the formula $\alpha = My + x$. To convert back from a linear index to 2-D coordinates, the formulas are $x = \alpha \mod M$ and $y = (\alpha - x) / M$.

### Neighbor
A pixel $p$ at coordinates $(x,y)$ has specific relationships with surrounding pixels, defined as its neighbors:
* **4-neighbors ($N_4(p)$):** These are the two horizontal and two vertical neighbors of $p$, located at $(x+1, y)$, $(x-1, y)$, $(x, y+1)$, and $(x, y-1)$.
* **Diagonal neighbors ($N_D(p)$):** These are the four diagonal neighbors located at $(x+1, y+1)$, $(x+1, y-1)$, $(x-1, y+1)$, and $(x-1, y-1)$.
* **8-neighbors ($N_8(p)$):** This is the combination of the 4-neighbors and the diagonal neighbors.



The set of these locations constitutes the "neighborhood" of $p$, which is considered "closed" if it includes pixel $p$ itself, and "open" if it does not.

### Digital Path
A digital path (or curve) between a starting pixel $p$ and an ending pixel $q$ is a sequence of distinct pixels where each adjacent pair of pixels in the sequence meets a specified adjacency criteria.
* The path is considered a **closed path** if the starting pixel $p$ and ending pixel $q$ are the same.
* Paths are categorized as **4-paths, 8-paths, or m-paths** based on the type of adjacency (4-, 8-, or m-adjacency) required between the pixels forming the path.

### Connectivity
Connectivity is a concept built upon digital paths to describe how pixels are grouped within a specific subset of an image (subset $S$).
* Two pixels are **connected** in $S$ if a digital path exists between them that consists solely of pixels within subset $S$.
* A **connected component** is the set of all pixels in $S$ that are connected to a specific pixel.
* If the entire subset $S$ is made up of just one connected component, it is called a **connected set**. 
* In image processing, a **region** of an image is defined as a connected set of pixels. Adjacent regions are those whose union forms a connected set, while non-adjacent regions are considered disjoint. Defining region adjacency requires specifying whether 4- or 8-adjacency is being used.
